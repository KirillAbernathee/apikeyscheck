Брать точную сумму со счёта

По одному api key сервис отдаёт только траты: сколько всего вам начислено, знает лишь сам аккаунт. Чтобы страница читала сумму со счёта, добавьте access token — в консоли Agent Router откройте личные настройки (Personal settings) и нажмите «Сгенерировать системный токен доступа» (Generate system access token).

Токен открывает доступ к аккаунту, поэтому уходит туда же, куда и ключ, — только на agentrouter.org. В браузере сохраняется вместе с ключом, если включена галочка «запомнить».

Как подключить ключ

Модели Claude (claude-opus-…) идут по протоколу Anthropic — адрес https://agentrouter.org, без /v1.

Остальные модели (gpt-…, glm-…) — по OpenAI-совместимому протоколу, адрес https://agentrouter.org/v1, с /v1.

Исключения из этого правила всего два: Kilo Code просит /v1 всегда, а Trae — никогда.
